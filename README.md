# PartyChat V1

Premium dark/neon social chat & gaming UI prototype.

## Run
1. Install Flutter.
2. Run `flutter pub get`
3. Run `flutter run`

## Next backend phase

- accounts and profiles

- coins/diamonds ledger
- moderation
